# Web Research

## Workflow
1. Turn the question into concrete search terms and a source list: official docs, release notes, HN, Reddit, and vendor pages.
2. Search and fetch multiple independent sources; prefer primary sources (official docs, repos, release notes) over summaries.
3. Verify claims against the actual page content; record URL, date, and title for each claim.
4. Synthesize a compact answer with citations; separate confirmed facts from uncertain ones.
5. State the as-of date and which sources were checked, including gaps.

## Rules
- Never answer from memory when the web is available; fetch first.
- Cite every factual claim with a source URL.
- Prefer primary sources; treat blogs and forum posts as secondary.
- Surface conflicts between sources instead of picking silently.
- Respect robots and terms; no scraping of paywalled or blocked content.

## Checklist
- [ ] Multi-source search performed; primary sources fetched.
- [ ] Claims carry citations (URL and date).
- [ ] Answer includes as-of date and source gaps.
