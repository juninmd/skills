# GitHub Triage Standards and Communication

Guidelines for AI-generated comments and status reporting.

## 1. AI Disclaimer
Every public comment **must** include this header:
```
> *This was generated by AI during triage.*
```

## 2. Needs Info Format
When requesting information, use this structure:
- **Established so far:** Points resolved during triage.
- **Still needed (@reporter):** Specific, actionable questions.

## 3. Resuming Sessions
- Parse prior triage notes before starting.
- Surface new reporter activity to the maintainer.
- Continue logic from the last known state; do not repeat questions.
