# Cloud Cost Optimizer Referência 📚
## AWS Cost Management

### 1. AWS Cost Explorer
**Description:** A tool to visualize, understand, and manage your AWS costs and usage over time.
**Key Features:** Custom reports, forecasting, RI utilization tracking.

### 2. AWS Trusted Advisor
**Description:** Provides real-time guidance to help you provision your resources following AWS best practices, including cost optimization.
**Key Checks:** Idle Load Balancers, Low Utilization Amazon EC2 Instances, Unassociated Elastic IP Addresses.

### 3. AWS Compute Optimizer
**Description:** Recommends optimal AWS resources for your workloads to reduce costs and improve performance by using machine learning to analyze historical utilization metrics.

## Azure Cost Management

### 1. Azure Cost Management + Billing
**Description:** A suite of tools to monitor, allocate, and optimize cloud costs.
**Key Features:** Cost analysis, budgets, advisor recommendations.

### 2. Azure Advisor
**Description:** Analyzes your configurations and usage telemetry and offers personalized, actionable recommendations to help you optimize your Azure resources.

## Google Cloud Cost Management

### 1. Billing Reports
**Description:** View your usage costs and analyze trends.

### 2. Recommender
**Description:** Generates recommendations for rightsizing, idle VM detection, and committed use discounts.
