# Cloud Cost Optimizer Forms

## 1. Cost Optimization Assessment (cost_assessment.md)

### Goal
Evaluate the current cloud infrastructure for potential cost savings.

### Fields
- **Project/Team Name:** [Name]
- **Cloud Provider:** [AWS/Azure/GCP]
- **Current Monthly Spend:** [$ Amount]
- **Budget Target:** [$ Amount]
- **Identified Waste:**
    - **Idle Resources:** [List of resources]
    - **Unused Storage:** [Volume size, potential savings]
- **Optimization Recommendations:**
    - **Rightsizing:** [Instance A -> Instance B]
    - **Commitment Plans:** [Purchase RI/Savings Plan]

## 2. Monthly FinOps Report (finops_report.md)

### Goal
Track spending against budget and report on optimization achievements.

### Fields
- **Reporting Period:** [Month/Year]
- **Total Spend:** [$ Amount]
- **Budget Variance:** [+/- %]
- **Top Spenders:**
    - **Service A:** [$ Amount]
    - **Team B:** [$ Amount]
- **Savings Realized:** [$ Amount from recent optimizations]
- **Upcoming Actions:** [Planned changes]
