# shadcn/ui: Blocks & Accessibility

## UI Blocks
Complete blocks (auth, dashboards, sidebars) available via:
- `list_blocks`: Browse categories.
- `get_block`: Retrieve full source.

## Accessibility (A11Y)
Built on Radix UI primitives:
- Keyboard navigation & Focus management included.
- ARIA attributes properly implemented.
- **Rule:** Maintain accessibility when customizing!

## Common Patterns
- **Forms:** Integration with `react-hook-form`.
- **Modals:** Using `Dialog` and `DialogContent`.
- **Tables:** Semantic `Table` and `TableBody` components.
