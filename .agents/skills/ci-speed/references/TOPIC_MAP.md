# ci-speed Reference Map

Read only the files needed for the current step.

| Reference | Open when |
|---|---|
| `measuring.md` | Recording a baseline, choosing the after window, reading a `compare` verdict, or writing the receipt |
| `causes.md` | `split` is done and a cause must be named and ranked; each row routes to a fix section |
| `fixes.md` | A cause is confirmed: cache, workflow shape, slow tests, flaky tests, or a push guard for coding agents |
| `NOTICE.md` | Checking the origin and MIT license of the adapted method and script |
