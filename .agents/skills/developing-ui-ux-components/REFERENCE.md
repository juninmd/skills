# UI/UX Component Developer Referência 📚
## Tools

### 1. `React`
**Description:** JavaScript library for building user interfaces.
**Key Concepts:**
- `JSX`: Syntax extension for JavaScript.
- `Components`: Building blocks of React apps.
- `Hooks`: Functions that let you use state and other features.

### 2. `Storybook`
**Description:** Frontend workshop for building UI components and pages in isolation.
**Comandos Comuns:**
- `npm run storybook`: Start the Storybook server.

### 3. `Tailwind CSS`
**Description:** Utility-first CSS framework.
**Key Concepts:**
- `Utility Classes`: Single-purpose classes (e.g., `flex`, `pt-4`, `text-center`).
- `Config`: `tailwind.config.js` for customization.
