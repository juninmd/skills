# Python Development

Esta skill otimiza o fluxo de desenvolvimento Python utilizando `uv`.

## Instructions
- Utilize `uv` para criação de ambientes e sincronização.
- Ative o `.venv` antes de qualquer execução de script.

## Scripts
- `scripts/create_venv.sh`: Automação de setup de ambiente.
