# Cloud Infrastructure Manager Reference

## Tools

### 1. `terraform`
**Description:** Infrastructure as Code tool for building, changing, and versioning infrastructure safely and efficiently.
**Common Commands:**
- `init`: Initialize a working directory containing Terraform configuration files.
- `plan`: Generate and show an execution plan.
- `apply`: Builds or changes infrastructure.
- `destroy`: Destroy the Terraform-managed infrastructure.

### 2. `aws` (AWS CLI)
**Description:** Unified tool to manage AWS services.
**Common Commands:**
- `ec2 run-instances`: Launch EC2 instances.
- `s3 ls`: List S3 buckets.
- `lambda create-function`: Create a Lambda function.

### 3. `gcloud` (Google Cloud SDK)
**Description:** Tool for creating and managing Google Cloud resources.
**Common Commands:**
- `compute instances create`: Create Compute Engine instances.
- `app deploy`: Deploy an App Engine application.
- `container clusters create`: Create a GKE cluster.
