# React Native Mobile Developer Referência 📚
## Core Components
- `View`: The fundamental component for building UI.
- `Text`: A component for displaying text.
- `Image`: A component for displaying images.
- `ScrollView`: A generic scrolling container.
- `FlatList`: A performant interface for rendering basic, flat lists.

## Libraries & Tools
- `React Navigation`: Routing and navigation for Expo and React Native apps.
- `Expo`: A framework and platform for universal React applications.
- `Redux Toolkit` / `Zustand`: State management solutions.
- `AsyncStorage`: Unencrypted, asynchronous, persistent, key-value storage system.

## CLI Commands
- `npx create-expo-app my-app`: Create a new Expo project.
- `npx react-native init MyApp`: Create a new React Native CLI project.
- `npx expo start`: Start the development server.
- `npx react-native run-android`: Run on Android device/emulator.
- `npx react-native run-ios`: Run on iOS simulator.
