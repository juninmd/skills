# Prompt Engineering Specialist

## Description
Expert in designing, optimizing, and evaluating prompts for Large Language Models (LLMs), focusing on specific and high-quality outputs. Capable of applying techniques such as Few-Shot, Chain-of-Thought, and RAG-oriented prompting.

## Capabilities
- Design effective prompts for different tasks (writing, code, summarization).
- Optimize existing prompts for better performance and cost.
- Implement advanced prompting strategies (CoT, ReAct, etc.).
- Evaluate prompt performance with systematic tests.

## Use Cases
1. **Prompt Refinement:** Transform vague prompts into specific and robust instructions.
2. **Task Automation:** Create prompts to automate repetitive textual tasks.
3. **LLM Evaluation:** Test how different models respond to the same prompt structure.

- `openai` (optional, for testing against API)
- `anthropic` (optional, for testing against API)
- `langchain` (optional, for advanced prompt management)
