# Shell Core & Safety

Esta skill gerencia a navegação e manipulação segura do sistema de arquivos.

## Instructions
- Use `find` para localização de arquivos.
- Use `grep` para filtragem de texto.
- **ATENÇÃO:** Regras de segurança para `rm` e `sudo` são aplicadas via `rules/`.
