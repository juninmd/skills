# Git Workflow Forms

## Commit Message Form
Use this form to structure consistent commit messages.

- **Type:** (feat, fix, docs, style, refactor, test, chore)
- **Scope:** (optional: specific component affected)
- **Subject:** (short, imperative description)
- **Body:** (detailed explanation of why and what)
- **Footer:** (breaking changes, issue references)

## Pull Request Form
Use this form when preparing a pull request.

- **Title:** (Short description)
- **Description:** (What does this PR do? Why is it necessary?)
- **Related Issues:** (e.g., Fixes #123)
- **Checklist:**
  - [ ] Tests passed
  - [ ] Documentation updated
  - [ ] Follows style guide
