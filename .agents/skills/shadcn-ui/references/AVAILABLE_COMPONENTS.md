# shadcn/ui: Available Components

shadcn/ui provides 50+ components built with Radix UI and Tailwind CSS.

## Key Categories
- **Layout:** Accordion, Card, Tabs, Collapsible, Separator.
- **Forms:** Button, Input, Select, Checkbox, Switch, Textarea.
- **Data Display:** Table, Badge, Avatar, Progress, Skeleton.
- **Navigation:** Nav Menu, Tabs, Breadcrumb, Pagination.
- **Overlays:** Dialog, Sheet, Popover, Tooltip, Alert Dialog.
- **Feedback:** Alert, Toast, Sonner, Command.

## Key Blocks
Includes pre-built layouts for Auth, Dashboards, and Calendars. Access via `list_blocks`.
