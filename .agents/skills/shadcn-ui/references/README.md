## Core Workflow
1. **Discovery:** List tools/components.
2. **Setup:** Initialize `components.json`.
3. **Integration:** `add` components via CLI.
4. **Customization:** Apply HSL variables and `cva` variants.
5. **QA:** Validate types and A11y.
