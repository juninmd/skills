# shadcn/ui: Component Catalog

Full reference of components organized by category.

## Categories
- [Layout & Structure](./CATALOG_LAYOUT.md) (Accordion, Card, Tabs, etc.)
- [Form & Inputs](./CATALOG_FORMS.md) (Button, Input, Select, etc.)
- [Data & Feedback](./CATALOG_DATA.md) (Table, Badge, Toast, etc.)
- [Overlays & Navigation](./CATALOG_OVERLAYS.md) (Dialog, Sheet, Nav Menu, etc.)
- [Advanced & Utilities](./CATALOG_ADVANCED.md) (Carousel, Command, Resizable, etc.)

## Component Composition
Common bundles:
- **Forms:** `form input label button select checkbox`
- **Data:** `table badge avatar progress skeleton`
- **Auth:** `card input label button tabs`

## Updates
Use `add` to overwrite or `diff` to see changes.
```bash
npx shadcn@latest add button
npx shadcn@latest diff button
```
