# shadcn/ui: Catalog - Overlays & Navigation

### Dialog & Alert Dialog
`npx shadcn@latest add dialog` / `alert-dialog`
Modal overlays. Alert Dialog is for critical confirmations.
Sub: `DialogTrigger`, `DialogContent`, `AlertDialogAction`.

### Sheet & Popover
- **Sheet:** `npx shadcn@latest add sheet`. Side panels (top/right/bottom/left).
- **Popover:** `npx shadcn@latest add popover`. Floating content.

### Tooltip & Hover Card
- **Tooltip:** `npx shadcn@latest add tooltip`. Context on hover.
- **Hover Card:** `npx shadcn@latest add hover-card`. Detailed user previews.

### Navigation
- **Navigation Menu:** `npx shadcn@latest add navigation-menu`. Accessible dropdowns.
- **Breadcrumb:** `npx shadcn@latest add breadcrumb`. Location hierarchy.
- **Pagination:** `npx shadcn@latest add pagination`. Page navigation.
