# shadcn/ui: Setup Guide

## Quick Start (New Project)
The easiest way is using the `create` command:
```bash
npx shadcn@latest create
```
Choose your framework, visual style (Vega, Nova, Maia, etc.), and component library (Radix or Base UI).

## Existing Project Setup
1. **Init:** `npx shadcn@latest init`
2. **Config:** Choose Style, Base Color, and CSS Variables.
3. **Paths:** Ensure `@/*` alias is in `tsconfig.json`.
