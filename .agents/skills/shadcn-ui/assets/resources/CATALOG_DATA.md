# shadcn/ui: Catalog - Data & Feedback

### Table
`npx shadcn@latest add table`
Sub: `TableHeader`, `TableBody`, `TableCell`. Best with `@tanstack/react-table`.

### Progress & Skeleton
- **Progress:** `npx shadcn@latest add progress`. `value` (0-100).
- **Skeleton:** `npx shadcn@latest add skeleton`. Loading states.

### Status Indicators
- **Badge:** `npx shadcn@latest add badge`. Variants: `default`, `outline`.
- **Avatar:** `npx shadcn@latest add avatar`. `AvatarImage`, `AvatarFallback`.

### Feedback
- **Alert:** `npx shadcn@latest add alert`. `AlertTitle`, `AlertDescription`.
- **Toast:** `npx shadcn@latest add toast`. Via `useToast()` hook.
- **Sonner:** `npx shadcn@latest add sonner`. Rich notifications.
