# shadcn/ui: Catalog - Advanced & Utilities

### Advanced Interactions
- **Carousel:** `npx shadcn@latest add carousel`. Embla-based slideshow.
- **Drawer:** `npx shadcn@latest add drawer`. Bottom sheet for mobile.
- **Resizable:** `npx shadcn@latest add resizable`. Split-view layouts.

### User Utilities
- **Command:** `npx shadcn@latest add command`. Search/CMD palette. Best with `cmdk`.
- **Scroll Area:** `npx shadcn@latest add scroll-area`. Custom scrollbars.
- **Aspect Ratio:** `npx shadcn@latest add aspect-ratio`. 16:9, 4:3, etc.

### Date & Time
- **Calendar:** `npx shadcn@latest add calendar`. `react-day-picker` based.
- **Date Picker:** `npx shadcn@latest add date-picker`. Calendar + Popover.
