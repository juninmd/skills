# shadcn/ui: Catalog - Layout & Structure

### Accordion
`npx shadcn@latest add accordion`
Collapsible content. Props: `type`, `collapsible`.

### Card
`npx shadcn@latest add card`
Sub: `CardHeader`, `CardTitle`, `CardContent`, `CardFooter`.

### Tabs
`npx shadcn@latest add tabs`
Sub: `TabsList`, `TabsTrigger`, `TabsContent`.

### Separator
`npx shadcn@latest add separator`
Visual divider. Props: `orientation`.

### Collapsible
`npx shadcn@latest add collapsible`
Show/hide with animation. Props: `open`.
