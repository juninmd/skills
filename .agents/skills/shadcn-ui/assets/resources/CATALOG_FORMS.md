# shadcn/ui: Catalog - Form & Inputs

### Button
`npx shadcn@latest add button`
Variants: `default`, `destructive`, `outline`, `ghost`, `link`.

### Input & Textarea
`npx shadcn@latest add input` / `textarea`
Standard text fields. Use with `Label`.

### Select & Combobox
`npx shadcn@latest add select` / `combobox`
Selection and search. Apps: `cmdk` for combobox.

### Toggles
- **Checkbox:** `npx shadcn@latest add checkbox`
- **Switch:** `npx shadcn@latest add switch`
- **Radio:** `npx shadcn@latest add radio-group`

### Form (Validation)
`npx shadcn@latest add form`
Integration with `react-hook-form` and `zod`.
Sub: `FormField`, `FormItem`, `FormLabel`, `FormControl`.
