# Data Analyst Reference

## Tools

### 1. `pandas` (Python)
**Description:** Powerful data manipulation and analysis library.
**Common Commands:**
- `pd.read_csv('file.csv')`: Load data.
- `df.describe()`: Summary statistics.
- `df.groupby('col').mean()`: Aggregation.

### 2. `matplotlib` / `seaborn` (Python)
**Description:** Libraries for creating static, animated, and interactive visualizations.
**Common Commands:**
- `plt.plot(x, y)`: Line plot.
- `sns.histplot(data=df, x='col')`: Histogram.
- `plt.savefig('plot.png')`: Save figure.

### 3. `scikit-learn` (Python)
**Description:** Machine learning library for predictive data analysis.
**Common Commands:**
- `LinearRegression()`: Linear model.
- `KMeans()`: Clustering.
