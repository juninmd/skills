# Frontend Aesthetics Guidelines

Technical standards for producing visually striking and distinctive interfaces.

## 1. Typography
- Avoid generic fonts (Arial, Inter, Roboto).
- Pair a distinctive display font with a refined body font.
- Use unexpected, characterful choices that elevate the brand.

## 2. Color and Theme
- Use CSS variables for a cohesive system.
- Prioritize dominant colors with sharp accents over even distributions.
- Create atmosphere with textures, grain overlays, and layered transparencies.

## 3. Spatial Composition
- Use unexpected layouts: asymmetry, overlap, diagonal flow.
- Break the grid intentionally.
- Balance generous negative space with areas of controlled density.

## 4. Motion and Depth
- Focus on high-impact moments (orchestrated page loads, staggered reveals).
- Prioritize CSS-only solutions where possible.
- Avoid "AI slop" patterns like cliched purple-on-white gradients.
