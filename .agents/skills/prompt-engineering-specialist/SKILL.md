# Prompt Engineering Specialist

## Description
Expert in designing, optimizing, and evaluating prompts for Large Language Models (LLMs) to achieve specific, high-quality outputs. Capable of implementing techniques like Few-Shot, Chain-of-Thought, and RAG-aware prompting.

## Capabilities
- Design effective prompts for various tasks (creative writing, coding, summarization).
- Optimize existing prompts for better performance and cost-efficiency.
- Implement advanced prompting strategies (CoT, ReAct, etc.).
- Evaluate prompt performance using systematic testing.

## Use Cases
1. **Refining Prompts:** Improving a vague prompt to be more specific and robust.
2. **Task Automation:** Creating prompts to automate repetitive text-based tasks.
3. **LLM Evaluation:** Testing how different models respond to the same prompt structure.

## Dependencies
- `openai` (optional, for testing against API)
- `anthropic` (optional, for testing against API)
- `langchain` (optional, for advanced prompt management)
