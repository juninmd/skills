# Kubernetes Operations

Esta skill auxilia no diagnóstico e operação de ambientes Kubernetes.

## Instructions
- Use `kubectl get pods` para monitorar saúde.
- Use `kubectl describe` para investigar falhas de agendamento.
- Use `kubectl logs -f` para debugar erros em tempo real.
