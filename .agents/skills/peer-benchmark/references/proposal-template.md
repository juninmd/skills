# Proposal template

Open when step 6 starts. One block per gap; rank blocks by impact over effort.

```markdown
### P<n>: <change in one line>
- Gap: <what peers do, with 2+ links>
- Baseline (target): <metric = value> (`<command>`, <version>, <date>)
- Benchmark (peers): <peer = value> (`<command>`, <version>, <date>) or "claimed: <source>"
- Expected gain / cost: <number or range> / <effort in days>
- Check after change: `<command>` -> <passing condition>
- Risk and license note: <breakage, attribution>
```

Report layout: header (goal, budget, date) · target baseline · peers table · feature matrix · benchmarks table · proposals P0/P1/P2 · deliberate divergences · appendix of raw excerpts.
