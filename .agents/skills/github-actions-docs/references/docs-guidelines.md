# GitHub Actions Documentation Guidelines

Standards for answering documentation-based questions.

## 1. Response Requirements
- **Directness:** Start with a direct answer.
- **Authoritativeness:** Provide exact GitHub docs links for every claim.
- **Clarity:** Provide YAML only if requested or essential for syntax explanation.
- **Inference:** Mark combined insights explicitly as `Inference:`.
- **Brevity:** Keep answers compact unless a walkthrough is requested.

## 2. Common Mistakes
- **Memory-based:** Answering without verifying current docs.
- **Broad Linking:** Linking landing pages instead of specific sections.
- **Category Confusion:** Mixing up composite actions vs. reusable workflows.
- **Security Lag:** Suggesting static keys instead of OIDC.
- **Scope Creep:** Treating generic repo operations as Actions questions.
