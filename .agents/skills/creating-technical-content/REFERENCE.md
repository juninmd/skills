# Technical Content Creator Referência 📚
## Tools

### 1. `Markdown`
**Description:** Lightweight markup language for creating formatted text using a plain-text editor.
**Common Syntax:**
- `# Heading 1`
- `**Bold**`
- `[Link](url)`
- ````code block````

### 2. `Mermaid`
**Description:** JavaScript based diagramming and charting tool that renders Markdown-inspired text definitions to create and modify diagrams dynamically.
**Common Syntax:**
- `graph TD; A-->B;` (Flowchart)
- `sequenceDiagram; A->>B: Hello;` (Sequence Diagram)

### 3. `Hugo` / `Jekyll` / `Docusaurus`
**Description:** Static site generators often used for technical documentation.
