# Game Mechanics Designer Reference

## Tools

### 1. `Pygame` (Python)
**Description:** A set of Python modules designed for writing video games.
**Common Commands:**
- `pygame.sprite.Sprite`: Base class for visible game objects.
- `pygame.Rect.colliderect()`: Check for collision.
- `pygame.time.Clock()`: Manage frame rate.

### 2. `Unity` (C#)
**Description:** Real-time 3D development platform.
**Key Concepts:**
- `MonoBehaviour`: Base class for every script.
- `Rigidbody`: Component for physics simulation.
- `Collider`: Component for collision detection.

### 3. `Godot` (GDScript/C#)
**Description:** Open source game engine.
**Key Concepts:**
- `Node`: The basic building block.
- `Scene`: A collection of nodes.
- `Signal`: Mechanism for communication between objects.
