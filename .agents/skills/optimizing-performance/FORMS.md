# Performance Optimizer Formulários 📋
## 1. Performance Audit Request (perf_audit.md)

### Goal
Request a performance analysis for a specific component.

### Fields
- **Target Component:** [Function/Endpoint/Service]
- **Observed Issue:** [Slow response/High CPU/Memory Leak]
- **Current Metrics:** [Latency/Throughput]
- **Target Metrics:** [Desired Latency/Throughput]

## 2. Optimization Report (optimization_report.md)

### Goal
Document the results of performance optimization efforts.

### Fields
- **Target:** [Component Optimized]
- **Baseline Metrics:**
    - **Latency:** [Value]
    - **Throughput:** [Value]
    - **Resource Usage:** [Value]
- **Optimizations Applied:**
    - [Optimization 1]
    - [Optimization 2]
- **Post-Optimization Metrics:**
    - **Latency:** [Value]
    - **Throughput:** [Value]
    - **Resource Usage:** [Value]
- **Improvement:** [Percentage]
