# Structured Web Research

## Objective
Generate reliable answers based on high-quality external sources.

## Flow
1. Decompose the question into objective sub-questions.
2. Research prioritizing official sources and primary documentation.
3. Select sources by authority, timeliness, and technical precision.
4. Extract verifiable evidence and version context.
5. Synthesize with citations and explicit handling of conflicts.

## Best Practices
- Iteratively refine searches.
- Verify critical facts in more than one source.
- Report uncertainty when there is insufficient evidence.
