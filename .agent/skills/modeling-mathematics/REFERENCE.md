# Mathematical Modeler Reference

## Tools

### 1. `NumPy`
**Description:** Fundamental package for scientific computing with Python.
**Common Commands:**
- `np.array([1, 2, 3])`: Create array.
- `np.linalg.solve(a, b)`: Solve linear system.

### 2. `SciPy`
**Description:** Ecosystem for open-source software for mathematics, science, and engineering.
**Common Commands:**
- `scipy.optimize.minimize(fun, x0)`: Minimize function.
- `scipy.integrate.odeint(func, y0, t)`: Solve ODE.

### 3. `SymPy`
**Description:** Python library for symbolic mathematics.
**Common Commands:**
- `x = symbols('x')`: Define symbol.
- `solve(x**2 - 2, x)`: Solve equation symbolically.
