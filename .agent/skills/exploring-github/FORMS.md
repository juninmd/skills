# Form Filling Guide: GitHub Explorer

## Repository Search Form
To search for a repository, provide the following information:

| Field | Description | Example |
|-------|-------------|---------|
| Query | Keywords to search for | "machine learning", "fastapi" |
| Language | Programming language (optional) | "python", "typescript" |
| User/Org | Specific user or organization (optional) | "google", "facebook" |
| Sort | Sort criteria (optional) | "stars", "forks", "updated" |

## File Retrieval Form
To read a file, provide:

| Field | Description | Example |
|-------|-------------|---------|
| Owner | Repository owner | "octocat" |
| Repo | Repository name | "Hello-World" |
| Path | Path to the file | "README.md", "src/main.py" |
| Ref | Branch or tag (optional) | "main", "v1.0.0" |
