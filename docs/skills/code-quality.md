# Quality Skills

## `diagnostics`

Evidence-driven reproduction and isolation for bugs, flaky tests, regressions, DNS, HTTP, TLS, and timeouts.

## `expert-review`

Adversarial review of code, diffs, plans, and designs. Findings lead and include severity, evidence, impact, and remediation.

## `variant-analysis`

After one defect is understood: state it as a pattern, sweep the codebase for every sibling, triage each hit, and codify the lint rule that closes the class.
