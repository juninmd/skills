# Data Skills

## `data-engineering`

PostgreSQL, MongoDB, Redis, query plans, indexes, locks, schema migrations, rollback, backups, and vector-search storage.

The skill collects read-only evidence before proposing changes and requires approval for destructive production operations.

## `sql-authoring`

Writing correct, performant SQL and schema designs: query authoring, window functions, CTEs, joins, index design, ORM query translation, and migration-safe model changes.
