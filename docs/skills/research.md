# Research Skills

## `web-research`

Multi-source web research with cited evidence: search, fetch primary sources, verify claims, and synthesize answers with URLs, dates, and explicit gaps.

## `docs-verification`

Verifying knowledge against current official documentation: detecting outdated APIs, configs, and best practices, and updating or flagging stale local references.

## `knowledge-freshness`

Keeping stack knowledge current: live registry checks (npm, PyPI, GitHub releases), latest stable versions, EOL and breaking-change detection, and safe upgrade planning.

## `web-scraping`

Respectful, robust web data collection: API-first checks, rate limits, retries, caching, selector stability, pagination, and validated structured output.
