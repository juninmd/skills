# Infrastructure Skills

## `cloud-devops`

CI/CD, Docker, Kubernetes, Helm, IaC, cloud architecture, serverless workloads, and observability. Live mutations require explicit approval.

## `security-ops`

Vulnerability and dependency scanning, SBOMs, secret triage, access control, least privilege, and security review. Findings are prioritized by exploitability and impact.

## `observability`

SLO/SLI definition, structured logging, RED metrics, tracing, dashboard design, alert thresholds, and incident signal quality. Alerts page on SLO burn rate with owners and runbooks.

## `plugin-vetting`

Vetting a third-party skill, plugin, or MCP server before installing: pinned read, hidden-instruction and exfiltration sweep, least-privilege check, and re-vetting on every bump.
