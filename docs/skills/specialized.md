# Routing Guide

Use the narrowest domain that owns the outcome:

| Request | Skill |
|---|---|
| Reproduce a failure | `diagnostics` |
| Review an existing artifact | `expert-review` |
| Design module or service boundaries | `software-architecture` |
| Build an AI agent or MCP integration | `agent-engineering` |
| Design test coverage | `test-engineering` |
| Build a maintained CLI or generator | `tooling-dev` |
| Plan and prepare delivery work | `project-lifecycle` |

When two skills apply, load the outcome-owning skill first and use the second only for its specialist checks.
