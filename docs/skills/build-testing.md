# Testing and Tooling Skills

## `test-engineering`

TDD, unit and integration tests, unhappy paths, Vitest, property and mutation testing, flaky-test control, and performance evidence.

## `webapp-testing`

End-to-end testing in a real browser: Playwright, user journeys, forms, auth flows, responsive and keyboard checks, and failure traces.

## `tooling-dev`

CLI tools, automation, generators, structured output, stable exit codes, non-interactive use, and packaged-command smoke tests.

## `skill-creator`

Authoring agent skills: SKILL.md structure, frontmatter, workflows, checklists, reference routing, token budgets, and spec validation.

## `document-generation`

Generating docx, xlsx, pptx, and pdf documents from data, with shared styles, safe untrusted input, and programmatic output verification.

## `web-scraping`

Respectful, robust web data collection: API-first checks, rate limits, retries, caching, selector stability, pagination, and validated structured output.
