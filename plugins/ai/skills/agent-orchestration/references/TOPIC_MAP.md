# agent-orchestration Reference Map

Read only the files needed for the current task.

| Reference | Open when |
|---|---|
| `dynamic-workflows.md` | Choosing and composing a multi-agent pattern (fan-out, adversarial verification, tournament, loop until done, quarantine) or writing a workflow script for this task: [dynamic-workflows](dynamic-workflows.md) |
| `long-run-steering.md` | Setting up a long or unattended run: finish line, stop/continue rules, task file, end-of-run report, flagged-message fallback: [long-run-steering](long-run-steering.md) |
| `parallel-subagents.md` | Deciding whether a task can fan out to worktrees, cutting slices, writing worker briefs, staged delivery with review checkpoints: [parallel-subagents](parallel-subagents.md) |
| `multi-model-council.md` | An irreversible decision needs consensus across models or adversarial review hats with deterministic arbitration: [multi-model-council](multi-model-council.md) |
| `headless-agent-supervision.md` | An unattended headless run needs a supervisor for auth expiry, quota 429s, stalls, or crash classification: [headless-agent-supervision](headless-agent-supervision.md) |
