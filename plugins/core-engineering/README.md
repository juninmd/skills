# Core Engineering Plugin

Este plugin fornece um conjunto robusto de agentes e habilidades (skills) focados em arquitetura de software, desenvolvimento backend, design patterns e ferramentas de terminal.

## 🤖 Agents
- **Software Architect** (`software-architect`): Ajuda no design de sistemas escaláveis e tomada de decisões técnicas.
- **Feature Builder** (`feature-builder`): Focado em implementar novas features de ponta a ponta.
- **Refactoring Agent** (`refactoring-agent`): Especializado em melhorar a qualidade do código existente.

## 🛠️ Skills Incluídas
- **Design Patterns e Boas Práticas**: `applying-clean-code`, `applying-dry`, `applying-kiss`, `applying-solid`, `applying-yagni`, `architecting-distributed-systems`, `architecting-file-systems`.
- **Desenvolvimento e Ferramentas**: `developing-nestjs`, `developing-node`, `developing-python`, `developing-tooling`.
- **APIs e Banco de Dados**: `designing-graphql-schemas`, `integrating-apis`, `administrating-databases`, `cataloging-apis`.

Estas skills e agentes podem ser invocados diretamente nos fluxos de engenharia de backend e arquitetura através do Copilot/Gemini utilizando os caminhos lógicos de configuração, mantendo a estrutura original em `.agents` intacta.
