# Developer Experience and Scaffolding Plugin

Focado em ferramentas de produtividade, padrões de versionamento, scaffolding de projetos e automação de ciclos de desenvolvimento.

## 🛠️ Skills Incluídas
- **Scaffolding e Automação**: `scaffolding-projects`, `generating-skills`, `running-autonomous-loops`.
- **Ferramental e Git**: `configuring-vscode-copilot`, `managing-git`, `developing-tooling`.
- **Governança**: `reviewing-skills`, `setup-diagnose`.

## 🚀 Como Utilizar
Acione este plugin ao iniciar novos projetos, criar novas habilidades para agentes ou otimizar o ambiente de trabalho (VS Code/Git).
