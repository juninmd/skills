# Quality and Testing Plugin

Focado na garantia de qualidade contínua, testes de software e processos de revisão de código.

## 🤖 Agents
- **Quality Engineer** (`quality-engineer`): Engenheiro dedicado a testes de software, validações manuais/automatizadas e gestão de massa de dados.
- **Code Reviewer** (`code-reviewer`): Focado em reviews assíncronos e validação rigorosa das entregas.

## 🛠️ Skills Incluídas
- **Qualidade e Testes**: `managing-quality`, `validating-typescript`.

## 🚀 Como Utilizar
Utilize sempre que o foco da interação for criar suítes de teste ou validar a qualidade técnica de uma entrega.
