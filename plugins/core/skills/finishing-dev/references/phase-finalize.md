# Final review procedure
Owned by `finishing-dev`; this file is not a standalone skill. It adds only what a sustained delivery loop needs on top of SKILL.md steps 3-8 and the [review protocol](review-protocol.md); it does not repeat them.

Record `evidence.md` in the [loop workspace](../../starting-dev/references/loop-state.md), outside the repository: resolved base/head or candidate snapshot, code and security reviewer scope, findings, adjudication with evidence, fixes, final review result, exact checks with concise outcomes, the acceptance criteria checked line by line, and residual uncertainty. Keep secrets and private logs out of it. Write it before setting the loop stage to finalize; readiness then follows the [readiness procedure](phase-done.md).

A reviewer agreeing with another reviewer is not proof: verify each concrete trigger and consequence against the code. Do not require a different model when the client offers none; independent contexts and distinct lenses are the minimum.
