# Data and AI Plugin

Este plugin fornece utilitários e conhecimento especializado em engenharia de dados, ciência de dados, IA generativa, bases de conhecimento vetorial e operações em ML (MLOps).

## 🤖 Agents
*(Agentes genéricos atuam sob demanda neste contexto, utilizando habilidades profundas e especializadas).*

## 🛠️ Skills Incluídas
- **Processamento de Dados**: `analyzing-data`, `processing-nlp`.
- **Inteligência Artificial**: `engineering-prompts`, `managing-vector-databases`.
- **Operação e Ciclo de Vida**: `managing-mlops`.

## 🚀 Como Utilizar
Invoque essas diretrizes ao criar ou aprimorar fluxos de MLOps, prompts avançados (few-shot, RAG), análise e estruturação de dados grandes.
