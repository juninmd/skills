# Cloud and Platform Plugin

Especializado em infraestrutura como código (IaC), CI/CD, gerenciamento de Kubernetes, shell e operações GCP/Magalu Cloud.

## 🤖 Agents
- **Platform Engineer** (`platform-engineer`): Especialista em arquitetura e operação em nuvem.
- **Terminal Operator** (`terminal-operator`): Especializado na execução ágil e segura de comandos shell.

## 🛠️ Skills Incluídas
- **Infra e Cloud**: `managing-cloud-infrastructure`, `managing-iac`, `managing-gcp`.
- **Containers e Kubernetes**: `managing-docker-containers`, `managing-helm-charts`, `operating-k8s`, `securing-k8s`, `validating-dockerfile`.
- **Operações e CI/CD**: `operating-infrastructure`, `operating-shell`, `managing-cicd`, `operating-gitlab-cli`, `operating-ci-knife`.
- **Ferramentas e Custos**: `optimizing-cloud-costs`, `scaffolding-projects`.
- **Diagnóstico**: `diagnosing-rabbitmq`, `diagnosing-networks`.

## 🚀 Como Utilizar
Acione este plugin ao desenhar arquiteturas cloud, configurar pipelines no GitLab CI, criar manifestos e containers, ou depurar ambientes de rede e infraestrutura.
